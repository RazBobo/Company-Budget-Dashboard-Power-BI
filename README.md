# Company Budget Dashboard – Power BI

An interactive dashboard for analyzing departmental budget execution vs. planning.  
Includes calculated KPIs, clear visualizations, and business insights to support decision making.

## 📊 What's Included:
- `CompanyBudgetDashboard.pbix` – Power BI file with all data models, visuals, and calculations
- `Project_Overview_Presentation.pdf` – Summary of the project with explanations

## 🛠 Tools Used:
- Power BI
- Power Query
- DAX

## 🎯 Key Features:
- Budget utilization tracking per department
- Actual vs. planned comparisons
- Interactive filters and charts for better data exploration
- Visual KPIs for fast executive understanding
